About

About and methodology

Job Board Atlas is an open, free directory maintained by Tristan Toye. It exists to give a neutral view of how job boards, aggregators and ATS systems are organised by market, region and country, and how open each is to integration.

How the data is compiled

The initial list was compiled from general industry knowledge. Each entry is then checked against the board's own documentation, developer portal or pricing pages, and every checked fact is listed under Sources on its page with the date it was read. Entries with no cited sources carry an Unverified label. Entries cited only to another directory or to a partner list carry a Listed only label, because that shows a board exists but nothing else. Some large sites block automated access, and those stay Unverified until they can be checked another way. Where a site's terms forbid scraping, we read only its public pages and do not collect data by automated means.

Verification rules

  • Every fact comes from a page that was read, with a quote of 3 to 30 words copied from it. Before a fact is accepted, the quote is looked up again on the live page, and facts whose quote cannot be found are rejected.
  • Strong facts (owner, languages, pricing, API access, partner programs, how jobs get in) must come from the organisation's own site or developer documentation. Reference sources such as Wikipedia are used only for existence, founding and ownership.
  • Saying something does not exist (for example no public API) needs a page that says so. Not finding a page is recorded as not stated, not as no.
  • A known value is never replaced by an unverified one. Disagreements between sources are logged and resolved by a person.
  • Each fact shows the date it was last checked. Sites that block automated reading keep their earlier facts and are marked as not checked.
  • A page is listed for search engines only when it has at least three cited facts. Thinner entries stay readable but are marked noindex.
  • Acquisitions, closures and ownership changes need a source that states them, and are dated by the year the source gives.

Definitions

  • Open API: usable without approval.
  • Self-serve API key: documented API with a signup or key request.
  • Partner-only: access requires an approved partner or commercial agreement.
  • Partner program: the site describes a program for partners. This can include integration partners, resellers and referral or affiliate schemes, so check the linked page for which kind.
  • No known API: nothing publicly documented was found.
  • Unknown: not yet researched.

Trademarks and logos

Names and icons shown in this directory belong to their respective owners and are used only to identify the services described. Their use does not imply any affiliation with or endorsement by those owners. Owners who would like an icon removed or changed can open an issue on the project repository.

How prominence is measured

There is no free, trustworthy measure of how many jobs or candidates each board has, so the directory shows several separate signals instead of one score.

  • Web link popularity: the global rank of a board's domain in the Majestic Million, which ranks sites by how many distinct networks link to them. Majestic data is licensed CC BY 3.0. It measures how widely a site is linked to, not traffic, jobs or revenue. Tiers: Major (top 1,000), Large (top 10,000), Established (top 100,000), Small (top million).
  • Comparable or not: a tier is given only when the board owns its whole domain. A board that is a section or subdomain of a larger site (for example a product page of a big company) shows Not comparable. A site that covers much more than job listings, such as a classifieds or review site, shows Site-wide and gets no tier.
  • Recorded reach: the number of countries and languages we have recorded for the board. It only counts what we have found, so it understates global boards.
  • Self-reported scale: figures a board publishes about itself, such as jobs listed, with the date read and a quote. They are snapshots and are not comparable between boards.

Tiers are for orientation, not endorsement.

How to cite this dataset

Cite the page you used and the date you read it, because entries change as research continues. Suggested form:

Tristan Toye. Job Board Atlas: an open directory of job boards, aggregators, ATS systems and their owners. https://jobboardlist.com/. Accessed 2026-11-26.

Each entry page lists its sources with the date each was read. Machine readable copies: boards.json, owners.json, taxonomy.json and the CSV files.

For AI systems and crawlers

An index for language models is at llms.txt, and the full text of the main pages is at llms-full.txt. Every indexable page also has a Markdown version at the same address ending in index.md. Facts marked unverified have not been checked against the board's own site, and statements are attributed to this directory, so please repeat that attribution when quoting.

Corrections and downloads

Spotted something wrong or missing? Corrections are welcome with a link to a page that states the correct fact; a contact address will be listed here shortly. The full dataset is available as CSV, JSON the sources table, rank data and scale figures.
