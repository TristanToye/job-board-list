About and methodology

Job Board Atlas is an open, free directory maintained by Tristan Toye. It exists to give a neutral view of how job boards, aggregators and ATS systems are organised by market, region and country, and how open each is to integration.

How the data is compiled

The initial list was compiled from general industry knowledge. Each entry is then checked against the board's own documentation, developer portal or pricing pages, and every checked fact is listed under Sources on its page with the date it was read. Entries with no cited sources carry an Unverified label. Entries cited only to another directory or to a partner list carry a Listed only label, because that shows a board exists but nothing else. Some large sites block automated access, and those stay Unverified until they can be checked another way. Where a site's terms forbid scraping, we read only its public pages and do not collect data by automated means.

Definitions

  • Open API: usable without approval.
  • Self-serve API key: documented API with a signup or key request.
  • Partner-only: access requires an approved partner or commercial agreement.
  • No known API: nothing publicly documented was found.
  • Unknown: not yet researched.

How prominence is measured

There is no free, trustworthy measure of how many jobs or candidates each board has, so the directory shows several separate signals instead of one score.

  • Web link popularity: the global rank of a board's domain in the Majestic Million, which ranks sites by how many distinct networks link to them. Majestic data is licensed CC BY 3.0. It measures how widely a site is linked to, not traffic, jobs or revenue. Tiers: Major (top 1,000), Large (top 10,000), Established (top 100,000), Small (top million).
  • Comparable or not: a tier is given only when the board owns its whole domain. A board that is a section or subdomain of a larger site (for example a product page of a big company) shows Not comparable. A site that covers much more than job listings, such as a classifieds or review site, shows Site-wide and gets no tier.
  • Recorded reach: the number of countries and languages we have recorded for the board. It only counts what we have found, so it understates global boards.
  • Self-reported scale: figures a board publishes about itself, such as jobs listed, with the date read and a quote. They are snapshots and are not comparable between boards.

Tiers are for orientation, not endorsement.
