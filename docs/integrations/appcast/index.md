# Appcast integrations

Platforms Appcast connects to, each from a page on one party's own site.

## Applicant tracking systems

- Greenhouse: receives jobs from (https://support.greenhouse.io/hc/en-us/articles/4405801275931-Free-job-posts)
- Lever: integrates with (https://www.lever.co/integrations)

## Job boards and aggregators

- Indeed: integrates with (https://www.appcast.io/products/appcast-one/)
- LinkedIn: integrates with (https://www.appcast.io/products/appcast-one/)
- Talent.com: sends jobs to (https://www.talent.com/ats)
- ZipRecruiter: integrates with (https://www.appcast.io/products/appcast-one/)

Canonical page: https://jobboardlist.com/integrations/appcast/
