# Talent.com integrations

- Breezy HR: receives jobs from (https://www.talent.com/ats)
- Greenhouse: receives jobs from (https://www.talent.com/ats)
- iCIMS: receives jobs from (https://www.talent.com/ats)
- JazzHR: receives jobs from (https://www.talent.com/ats)
