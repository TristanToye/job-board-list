# JazzHR integrations

Platforms JazzHR connects to, each from a page on one party's own site.

## Job boards and aggregators

- Careerjet: integrates with (https://www.careerjet.com/recruiter/ats)
- Idealist: integrates with (https://www.jazzhr.com/integrations)
- Indeed: integrates with (https://www.jazzhr.com/integrations)
- LinkedIn: integrates with (https://www.jazzhr.com/integrations)
- Talent.com: sends jobs to (https://www.talent.com/ats)
- ZipRecruiter: integrates with (https://www.jazzhr.com/integrations)
