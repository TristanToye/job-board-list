# Taleez integrations

Platforms Taleez connects to, each from a page on one party's own site.

## Job boards and aggregators

- France Travail: sends jobs to (https://taleez.com/jobboards)
- Hellowork: sends jobs to (https://taleez.com/jobboards)
- Indeed: sends jobs to (https://taleez.com/jobboards)
