# JobTarget integrations

Platforms JobTarget connects to, each from a page on one party's own site.

## Applicant tracking systems

- ApplicantStack: receives jobs from (https://www.applicantstack.com/job-boards/)
- iCIMS: integrates with (https://www.jobtarget.com/job-advertising-solutions)

## Job boards and aggregators

- Indeed: sends jobs to (https://support.jobtarget.com/jobtarget-help-center/guide-to-posting-on-indeed-via-marketplace)
- LinkedIn: integrates with (https://www.jobtarget.com/job-advertising-solutions)
- ZipRecruiter: integrates with (https://www.jobtarget.com/job-advertising-solutions)
