# Breezy HR integrations

Platforms Breezy HR connects to, each from a page on one party's own site.

## Job boards and aggregators

- Careerjet: integrates with (https://www.careerjet.com/recruiter/ats)
- Reed: sends jobs to (https://www.reed.co.uk/recruiter/ats-integration)
- Talent.com: sends jobs to (https://www.talent.com/ats)

Canonical page: https://jobboardlist.com/integrations/breezy/
