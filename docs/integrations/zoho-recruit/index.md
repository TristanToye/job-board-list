# Zoho Recruit integrations

Platforms Zoho Recruit connects to, each from a page on one party's own site.

## Job boards and aggregators

- Adzuna: integrates with (https://www.zoho.com/recruit/supported-job-boards.html)
- CareerBuilder: sends jobs to (https://www.zoho.com/recruit/integrations.html)
- Dice: integrates with (https://www.zoho.com/recruit/supported-job-boards.html)
- Indeed: integrates with (https://www.zoho.com/recruit/supported-job-boards.html)
- Jooble: integrates with (https://www.zoho.com/recruit/supported-job-boards.html)
- LinkedIn: sends jobs to (https://www.zoho.com/recruit/integrations.html)
- WhatJobs: sends jobs to (https://www.zoho.com/recruit/supported-job-boards.html)
- ZipRecruiter: sends jobs to (https://www.zoho.com/recruit/supported-job-boards.html)
