# Recruitee integrations

Platforms Recruitee connects to, each from a page on one party's own site.

## Job boards and aggregators

- Google for Jobs: sends jobs to (https://recruitee.com/career-page-multiposting)
- Indeed: sends jobs to (https://recruitee.com/career-page-multiposting)
- LinkedIn: integrates with (https://recruitee.com/api-webhooks-integrations)

Canonical page: https://jobboardlist.com/integrations/recruitee/
