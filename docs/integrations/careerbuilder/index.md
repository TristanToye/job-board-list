# CareerBuilder integrations

Platforms CareerBuilder connects to, each from a page on one party's own site.

## Applicant tracking systems

- Ceipal: receives jobs from (https://www.ceipal.com/staffing-agency-software/applicant-tracking-system)
- Crelate: integrates with (https://www.crelate.com/pricing)
- JobDiva: integrates with (https://www.jobdiva.com/recruiting-software-third-party-integrations)
- Loxo: receives jobs from (https://www.loxo.co/products/ats)
- Pinpoint: integrates with (https://www.pinpointhq.com/integrations)
- RecruitBPM: integrates with (https://recruitbpm.com/integration)
- Workable: receives jobs from (https://help.workable.com/hc/en-us/articles/115013182007-Integrating-with-CareerBuilder)
- Workable: integrates with (https://help.workable.com/hc/en-us/sections/115003175147-Job-boards)
- Zoho Recruit: receives jobs from (https://www.zoho.com/recruit/integrations.html)

Canonical page: https://jobboardlist.com/integrations/careerbuilder/
