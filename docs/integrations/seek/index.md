# SEEK integrations

Platforms SEEK connects to, each from a page on one party's own site.

## Applicant tracking systems

- BambooHR: receives jobs from (https://www.bamboohr.com/integrations/preferred-apps)
- JobAdder: integrates with (https://jobadder.com/platform/operations/job-boards)
- Manatal: receives jobs from (https://www.manatal.com/)
- Pinpoint: integrates with (https://www.pinpointhq.com/integrations)
- Workable: receives jobs from (https://help.workable.com/hc/en-us/articles/115013336568-Integrating-with-Seek)

Canonical page: https://jobboardlist.com/integrations/seek/
