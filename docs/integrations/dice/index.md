# Dice integrations

Platforms Dice connects to, each from a page on one party's own site.

## Applicant tracking systems

- Ceipal: receives jobs from (https://www.ceipal.com/staffing-agency-software/applicant-tracking-system)
- Crelate: integrates with (https://www.crelate.com/pricing)
- RecruitBPM: receives jobs from (https://recruitbpm.com/integration)
- Workable: integrates with (https://help.workable.com/hc/en-us/sections/115003175147-Job-boards)
- Zoho Recruit: integrates with (https://www.zoho.com/recruit/supported-job-boards.html)

Canonical page: https://jobboardlist.com/integrations/dice/
