# Teamtailor integrations

Platforms Teamtailor connects to, each from a page on one party's own site.

## Job boards and aggregators

- Adzuna: integrates with (https://www.teamtailor.com/en/integrations)
- Careerjet: integrates with (https://www.teamtailor.com/en-us/integrations/careerjet/)
- LinkedIn: integrates with (https://www.teamtailor.com/en-us/integrations/)
- Reed: sends jobs to (https://www.reed.co.uk/recruiter/ats-integration)
