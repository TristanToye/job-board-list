# RecruitBPM integrations

Platforms RecruitBPM connects to, each from a page on one party's own site.

## Job boards and aggregators

- CareerBuilder: integrates with (https://recruitbpm.com/integration)
- Careerjet: sends jobs to (https://recruitbpm.com/integration)
- Dice: sends jobs to (https://recruitbpm.com/integration)
- Glassdoor: integrates with (https://recruitbpm.com/integration)
- Indeed: sends jobs to (https://recruitbpm.com/integration)
- Monster: integrates with (https://recruitbpm.com/integration)
- ZipRecruiter: sends jobs to (https://recruitbpm.com/integration)
