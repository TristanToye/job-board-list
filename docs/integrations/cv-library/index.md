# CV-Library integrations

Platforms CV-Library connects to, each from a page on one party's own site.

## Applicant tracking systems

- Eploy: receives jobs from (https://www.eploy.com/product/recruitment-marketing/multi-posting/)
- JobAdder: integrates with (https://jobadder.com/platform/operations/job-boards)
- Jobvite: integrates with (https://www.jobvite.com/marketplace/)
- Manatal: receives jobs from (https://www.manatal.com/)
- Pinpoint: integrates with (https://www.pinpointhq.com/integrations)
- Recruit CRM: integrates with (https://recruitcrm.io/pricing/)
- Voyager Infinity: integrates with (https://www.voyagersoftware.com/partners/)
- Workable: integrates with (https://help.workable.com/hc/en-us/sections/115003175147-Job-boards)

Canonical page: https://jobboardlist.com/integrations/cv-library/
