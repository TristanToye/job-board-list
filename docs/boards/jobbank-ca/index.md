# Job Bank

Job Bank is a government job site based in Canada.

- Website: https://www.jobbank.gc.ca
- Headquarters: Canada
- Founded: not recorded
- Owner: Government of Canada
- Languages: English, French
- API status: API key on request (https://www.jobbank.gc.ca/network)
- Partner program: yes
- Prominence: Not in top 1M
- Tags: API on request, Free to post, General, Government operated, Public employment service, Job board, Partner program, Public sector, XML feed
- Data status: partly verified against its own site

## How API access works

- How to get access: Request access to the XML feed of job postings (https://www.jobbank.gc.ca/network)
- Approval: Feed requests must meet listed conditions (https://www.jobbank.gc.ca/network)
- Data formats: XML feed of job postings (https://www.jobbank.gc.ca/network)
- What it covers: Shares Job Bank postings with other job boards via feed (https://www.jobbank.gc.ca/network)

## Quick answers

**Who owns Job Bank?** This directory records the parent of Job Bank as Government of Canada.

**Does Job Bank have an API?** According to this directory, Job Bank issues API keys or feeds on request. Documentation: https://www.jobbank.gc.ca/network.

**Which languages does Job Bank support?** This directory records Job Bank as supporting English, French.

**How many jobs does Job Bank list?** Job Bank reports 55,000 jobs advertised per month on its own site (as of 2026-11-05).

**Which platforms does Job Bank connect to?** According to this directory, Job Bank integrates with CareerBeacon, Google, Indeed, Jobillico, LinkedIn, Magnet and others.

**How do you get API access to Job Bank?** According to Job Bank's own documentation, access works like this: Request access to the XML feed of job postings.
