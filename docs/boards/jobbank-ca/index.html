Notes

Delivered by Employment and Social Development Canada. About page cites 55,000 jobs advertised per month and 371,000 registered employers. Terms of use prohibit scripts, robots and scrapers. Postings run 21 days. No public posting API is described. XML feed access is by request with eligibility criteria. The open data dataset on open.canada.ca has not been verified yet.
