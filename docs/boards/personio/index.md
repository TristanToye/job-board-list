## How API access works

- How to get access: API credentials created in Marketplace under Connected integrations (https://developer.personio.de/docs/getting-started-with-the-personio-api)
- Authentication: client_id and client_secret credentials; recruiting access token is predefined per account (https://developer.personio.de/docs/getting-started-with-the-personio-api)
- What it covers: Employee, attendance, absence, recruiting, custom report and webhook endpoints (https://developer.personio.de/docs/getting-started-with-the-personio-api)
