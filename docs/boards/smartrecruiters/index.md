## How API access works

- How to get access: Customers create API credentials in the Credential Manager (https://developers.smartrecruiters.com/docs/authentication)
- Authentication: API key sent in the X-SmartToken header (https://developers.smartrecruiters.com/docs/authentication-api-key)
- Data formats: REST endpoints (https://developers.smartrecruiters.com/docs/partners-job-board-api)
- What it covers: Job posting details for purchased job board postings (https://developers.smartrecruiters.com/docs/partners-job-board-api)
- Rate limits: Up to 10 requests per second for most endpoints (https://developers.smartrecruiters.com/docs/rate-limiting)
