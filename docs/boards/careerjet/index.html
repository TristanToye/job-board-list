Quick answers

What is Careerjet?

Careerjet is a job aggregator based in France.

Does Careerjet have an API?

According to this directory, Careerjet offers an API you can use with a self-serve key. Documentation: https://www.careerjet.com/partners/api.

Which languages does Careerjet support?

This directory records Careerjet as supporting English, French, German, Spanish, Italian, Portuguese, Dutch, Polish.

How large is Careerjet?

Careerjet ranks #59,493 among all websites by web link popularity (Majestic Million, 2026-11-06), in the Established tier. This measures how widely the site is linked to, not traffic or job volume.

Which platforms does Careerjet connect to?

According to this directory, Careerjet receives jobs from Workable; integrates with Pinpoint, Acquire4Hire, ApplicantPro, ApplicantStack, Arca24, Arcoro and others.
