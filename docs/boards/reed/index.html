Quick answers

What is Reed?

Reed is a job board based in United Kingdom. It was founded in 1960.

Who owns Reed?

This directory records the parent of Reed as Reed family.

Does Reed have an API?

According to this directory, Reed offers an API you can use with a self-serve key. Documentation: https://www.reed.co.uk/developers.

Which languages does Reed support?

This directory records Reed as supporting English.

How large is Reed?

Reed ranks #13,306 among all websites by web link popularity (Majestic Million, 2026-11-09), in the Established tier. This measures how widely the site is linked to, not traffic or job volume.

Which platforms does Reed connect to?

According to this directory, Reed receives jobs from Logic Melon, JobAdder, Fire Fish Software, Jobtrain, Teamtailor, Workable and others; integrates with Pinpoint.
