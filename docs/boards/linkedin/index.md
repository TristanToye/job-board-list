# LinkedIn

LinkedIn is a social network and board based in United States, focused on general/professional. It was founded in 2002.

- Website: https://www.linkedin.com/jobs
- Headquarters: United States
- Founded: 2002
- Owner: Microsoft (Subsidiary, since 2016)

## Quick answers

**Who owns LinkedIn?** According to this directory, LinkedIn is owned by Microsoft (subsidiary, since 2016).

**Does LinkedIn have an API?** According to this directory, LinkedIn restricts programmatic access to approved partners. Documentation: https://developer.linkedin.com/.

**Which languages does LinkedIn support?** This directory records LinkedIn as supporting English, Spanish, French, German, Italian, Portuguese, Dutch, Polish, Swedish, Danish, Norwegian, Finnish, Japanese, Korean, Chinese, Arabic, Turkish, Russian, Indonesian, Malay, Thai, Romanian, Czech, Bengali, Greek, Persian, Hindi, Hungarian, Hebrew, Marathi, Punjabi, Telugu, Tagalog, Ukrainian, Vietnamese.

**Which platforms does LinkedIn connect to?** According to this directory, LinkedIn receives jobs from Workable, Greenhouse; integrates with Oracle Recruiting Cloud, JazzHR, Pinpoint, iCIMS, Job Bank, Appcast and others.
