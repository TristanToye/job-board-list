## How API access works

- How to get access: Not required to be an iCIMS partner to build an integration (https://developer-community.icims.com/getting-started/integrating-icims)
- Approval: Marketplace integrations are reviewed by the ICIMS Developer Support Team, which says whether they are approved or rejected (https://developer-community.icims.com/getting-started/integrating-icims)
- Data formats: REST API (https://developer-community.icims.com/getting-started/integrating-icims)
- What it covers: Reads and writes the standard fields of the ATS data models an integration uses (https://developer-community.icims.com/getting-started/integrating-icims)
- Test environment: Sandbox environment set up after integration approval, for developing, testing and validating the integration (https://developer-community.icims.com/getting-started/integrating-icims)
