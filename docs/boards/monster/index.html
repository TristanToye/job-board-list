Monster

Monster is a job board based in PR, serving all kinds of roles. It restricts programmatic access to approved partners. A partner or integration program exists.

Merged with CareerBuilder in 2024. This entry is kept for reference and may no longer operate as a separate service. See CareerBuilder. Source. All closed, acquired and merged entries.

Quick answers

What is Monster?

Monster is a job board based in PR. It was founded in 1999.

Who owns Monster?

According to this directory, Monster is owned by BOLD Holdings (subsidiary, since 2025).

Does Monster have an API?

According to this directory, Monster restricts programmatic access to approved partners.

Which languages does Monster support?

This directory records Monster as supporting English, French, German, Dutch, Italian.

How large is Monster?

Monster ranks #1,845 among all websites by web link popularity (Majestic Million, 2026-11-09), in the Large tier. This measures how widely the site is linked to, not traffic or job volume.

Which platforms does Monster connect to?

According to this directory, Monster receives jobs from Workable, Greenhouse; integrates with Pinpoint.
