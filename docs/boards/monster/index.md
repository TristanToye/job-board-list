# Monster

Monster is a job board based in PR. It was founded in 1999.

- Website: https://www.monster.com
- Headquarters: PR
- Founded: 1999
- Owner: BOLD Holdings (Subsidiary, since 2025)
- Languages: English, French, German, Dutch, Italian
- API status: Partner-only API
- Partner program: yes
- Prominence: #1,845 globally, tier Large
- Tags: Partner-only API, General, Job board, Partner program, Subscription, XML feed
- Data status: secondary sources only

## Quick answers

**Who owns Monster?** According to this directory, Monster is owned by BOLD Holdings (subsidiary, since 2025).

**Does Monster have an API?** According to this directory, Monster restricts programmatic access to approved partners.

**Which languages does Monster support?** This directory records Monster as supporting English, French, German, Dutch, Italian.

**How large is Monster?** Monster ranks #1,845 among all websites by web link popularity (Majestic Million, 2026-11-06), in the Large tier. This measures how widely the site is linked to, not traffic or job volume.

**Which platforms does Monster connect to?** According to this directory, Monster receives jobs from Workable, Greenhouse; integrates with Pinpoint.
