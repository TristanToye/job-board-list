Quick answers

What is CV-Library?

CV-Library is a job board based in the United Kingdom. It was founded in 2000.

Who owns CV-Library?

This directory records the parent of CV-Library as Lee Biggins.

Does CV-Library have an API?

According to this directory, CV-Library restricts programmatic access to approved partners. Documentation: https://www.cv-library.co.uk/developers.

Which languages does CV-Library support?

This directory records CV-Library as supporting English.

How large is CV-Library?

CV-Library ranks #37,351 among all websites by web link popularity (Majestic Million, 2026-11-23), in the Established tier. This measures how widely the site is linked to, not traffic or job volume.

Which platforms does CV-Library connect to?

According to this directory, CV-Library receives jobs from Eploy, Manatal; integrates with Pinpoint, Workable, Jobvite, JobAdder, Voyager Infinity, Recruit CRM.
