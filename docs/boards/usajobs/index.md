# USAJOBS

USAJOBS is a government job site based in the United States, focused on public sector. It was founded in 1996.

- Website: https://www.usajobs.gov
- Headquarters: United States
- Founded: 1996
- Owner: US OPM
- Languages: English
- API status: Self-serve API key (https://developer.usajobs.gov/)
- Partner program: n/a
- Prominence: #5,522 globally, tier Large
- Tags: Self-serve API, Free to post, Government operated, Public employment service, Job board, Public sector
- Data status: partly verified against its own site

## How API access works

- How to get access: API key requested by filling out an application on the API Request page (https://developer.usajobs.gov/guides/authentication)
- Authentication: API key sent in an Authorization-Key request header, with the requester's email in the User-Agent header and Host set to data.usajobs.gov. Codelist endpoints need no authentication (https://developer.usajobs.gov/guides/authentication)
- Data formats: REST API using HTTP GET requests (https://developer.usajobs.gov/api-reference/job-apis)
- What it covers: Job search, historic job announcements and announcement text endpoints at data.usajobs.gov (https://developer.usajobs.gov/api-reference/job-apis)
- Rate limits: Search Jobs API: maximum of 10,000 rows per query and 500 rows per page. Code List API and Dynamic Search have no stated limits (https://developer.usajobs.gov/guides/rate-limiting)
