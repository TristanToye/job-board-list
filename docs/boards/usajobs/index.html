Quick answers

What is USAJOBS?

USAJOBS is a government job site based in United States, focused on public sector. It was founded in 1996.

Who owns USAJOBS?

This directory records the parent of USAJOBS as US OPM.

Does USAJOBS have an API?

According to this directory, USAJOBS offers an API you can use with a self-serve key. Documentation: https://developer.usajobs.gov/.

This directory records USAJOBS as supporting English.
