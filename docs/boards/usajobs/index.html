How API access works

How to get access
API key requested by filling out an application on the API Request page source
Authentication
API key sent in an Authorization-Key request header, with the requester's email in the User-Agent header and Host set to data.usajobs.gov. Codelist endpoints need no authentication source
Data formats
REST API using HTTP GET requests source
What it covers
Job search, historic job announcements and announcement text endpoints at data.usajobs.gov source
Rate limits
Search Jobs API: maximum of 10,000 rows per query and 500 rows per page. Code List API and Dynamic Search have no stated limits source

Quick answers

What is USAJOBS?

USAJOBS is a government job site based in the United States, focused on public sector. It was founded in 1996.

Who owns USAJOBS?

This directory records the parent of USAJOBS as US OPM.

Does USAJOBS have an API?

According to this directory, USAJOBS offers an API you can use with a self-serve key. Documentation: https://developer.usajobs.gov/.

Which languages does USAJOBS support?

This directory records USAJOBS as supporting English.

How large is USAJOBS?

USAJOBS ranks #5,522 among all websites by web link popularity (Majestic Million, 2026-11-23), in the Large tier. This measures how widely the site is linked to, not traffic or job volume.

How do you get API access to USAJOBS?

According to USAJOBS's own documentation, access works like this: API key requested by filling out an application on the API Request page; requests authenticate with API key sent in an Authorization-Key request header, with the requester's email in the User-Agent header and Host set to data.usajobs.gov. Codelist endpoints need no authentication.
