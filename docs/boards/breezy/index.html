Quick answers

What is Breezy HR?

Breezy HR is an applicant tracking system based in United States, focused on applicant tracking system.

Does Breezy HR have an API?

According to this directory, Breezy HR offers an API you can use with a self-serve key. Documentation: https://developer.breezy.hr.

How large is Breezy HR?

Breezy HR ranks #11,990 among all websites by web link popularity (Majestic Million, 2026-11-11), in the Established tier. This measures how widely the site is linked to, not traffic or job volume.

Which platforms does Breezy HR connect to?

According to this directory, Breezy HR sends jobs to Talent.com, Reed; integrates with Careerjet.

How do you get API access to Breezy HR?

According to Breezy HR's own documentation, access works like this: Personal API key created from the API Keys tab in the Breezy account; requests authenticate with Personal Access Token in the Authorization header; session tokens from the signin endpoint also supported.
