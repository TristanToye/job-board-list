# Indeed

Indeed is an aggregator and board based in United States. It was founded in 2004.

- Website: https://www.indeed.com
- Headquarters: United States
- Founded: 2004
- Owner: Recruit Holdings Co., Ltd. (Subsidiary, since 2012)
- Languages: English, Spanish, French, German, Italian, Portuguese, Dutch, Polish, Swedish, Danish, Norwegian, Finnish, Japanese, Korean, Chinese, Arabic, Turkish
- API status: Partner-only API (https://docs.indeed.com)
- Partner program: yes

## Quick answers

**Who owns Indeed?** According to this directory, Indeed is owned by Recruit Holdings Co., Ltd. (subsidiary, since 2012).

**Does Indeed have an API?** According to this directory, Indeed restricts programmatic access to approved partners. Documentation: https://docs.indeed.com.

**Which languages does Indeed support?** This directory records Indeed as supporting English, Spanish, French, German, Italian, Portuguese, Dutch, Polish, Swedish, Danish, Norwegian, Finnish, Japanese, Korean, Chinese, Arabic, Turkish.

**How large is Indeed?** Indeed ranks #340 among all websites by web link popularity (Majestic Million, 2026-11-12), in the Major tier. This measures how widely the site is linked to, not traffic or job volume.

**Which platforms does Indeed connect to?** According to this directory, Indeed receives jobs from Broadbean, Workable, Greenhouse, Recruitee; integrates with Oracle Recruiting Cloud, JazzHR, Pinpoint, Job Bank, Appcast, Lever and others.
