Jobsuche (Bundesagentur fur Arbeit)

Jobsuche (Bundesagentur fur Arbeit) is a government job site based in Germany, serving all kinds of roles. It offers an API you can use with a self-serve key. Not applicable (public body or open source of data).

Quick answers

What is Jobsuche (Bundesagentur fur Arbeit)?

Jobsuche (Bundesagentur fur Arbeit) is a government job site based in Germany.

Who owns Jobsuche (Bundesagentur fur Arbeit)?

This directory records the parent of Jobsuche (Bundesagentur fur Arbeit) as Federal Employment Agency.

Does Jobsuche (Bundesagentur fur Arbeit) have an API?

According to this directory, Jobsuche (Bundesagentur fur Arbeit) offers an API you can use with a self-serve key. Documentation: https://jobsuche.api.bund.dev.

Which languages does Jobsuche (Bundesagentur fur Arbeit) support?

This directory records Jobsuche (Bundesagentur fur Arbeit) as supporting German, English.
