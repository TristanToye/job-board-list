## How API access works

- How to get access: Dedicated partner feed is provisioned by Ashby on request (https://developers.ashbyhq.com/docs/dedicated-partner-job-feeds)
- Authentication: API key as HTTP Basic auth username with a blank password (https://developers.ashbyhq.com/reference/authentication)
- Data formats: RPC-style API where most endpoints are POST requests with JSON bodies (https://developers.ashbyhq.com/reference/introduction)
- What it covers: Published job postings of opted-in customers delivered in a partner feed (https://developers.ashbyhq.com/docs/dedicated-partner-job-feeds)
