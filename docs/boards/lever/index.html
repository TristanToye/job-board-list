Quick answers

What is Lever?

Lever is an applicant tracking system based in United States, focused on applicant tracking system.

Who owns Lever?

This directory records the parent of Lever as Employ Inc..

Does Lever have an API?

According to this directory, Lever offers an API you can use with a self-serve key. Documentation: https://github.com/lever/postings-api.

How large is Lever?

Lever ranks #3,942 among all websites by web link popularity (Majestic Million, 2026-11-11), in the Large tier. This measures how widely the site is linked to, not traffic or job volume.

Which platforms does Lever connect to?

According to this directory, Lever sends jobs to Reed; integrates with Indeed, LinkedIn, AcquireROI, Appcast, Bandana, Boostie and others.

How do you get API access to Lever?

According to Lever's own documentation, access works like this: API keys are created by the customer in Lever Settings; requests authenticate with API key sent as the basic auth username with a blank password.
