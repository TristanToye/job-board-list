## How API access works

- How to get access: API keys are created by the customer in Lever Settings (https://hire.lever.co/developer/documentation)
- Approval: OAuth apps must be registered through the partner integration program (https://hire.lever.co/developer/documentation)
- Authentication: API key sent as the basic auth username with a blank password (https://hire.lever.co/developer/documentation)
- Data formats: JSON over HTTPS (https://hire.lever.co/developer/documentation)
- What it covers: List endpoints for opportunities, users and postings, plus webhooks (https://hire.lever.co/developer/documentation)
- Rate limits: 10 requests per second per API key by default, with bursts to 20 (https://hire.lever.co/developer/documentation)
- Test environment: Partner sandbox account and sandbox API base URL (https://hire.lever.co/developer/partner)
