Quick answers

Which ATS have a public API for job postings?

According to the platforms checked so far, Greenhouse publishes job data openly without a key, and Ashby, BambooHR, Breezy HR, JazzHR, Jobvite, Lever, Oracle Recruiting Cloud, Personio, Pinpoint, Recruitee, Rippling Recruiting, SmartRecruiters, Teamtailor and Workable offer an API you can use with a self-serve key. Check each platform for what its API covers.

Which ATS APIs need a partnership or approval?

None of the platforms checked so far restricts API access to approved partners. iCIMS issues access on request.

Which ATS publish an open job feed without a key?

Greenhouse. Job boards and aggregators can use this feed to pull an employer's open roles without a commercial agreement.
