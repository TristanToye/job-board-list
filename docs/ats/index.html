Applicant tracking systems

Which ATS platforms expose public job feeds, which need keys, and which run partner marketplaces, with owners and customer segments. These systems are where most employers publish their jobs from, so their openness decides how jobs reach boards.

Quick answers

Which ATS have a public API for job postings?

According to the platforms checked so far, Greenhouse publishes job data openly without a key, and Ashby, Atlas, BambooHR, Breezy HR, JazzHR, Jobvite, Lever, Oracle Recruiting Cloud, Personio, Pinpoint, Recruitee, Rippling Recruiting, SmartRecruiters, Teamtailor and Workable offer an API you can use with a self-serve key. Check each platform for what its API covers.

Which ATS APIs need a partnership or approval?

Bullhorn and Oracle Taleo restrict API access to approved partners, and iCIMS and PCRecruiter issue access on request.

Which ATS publish an open job feed without a key?

Greenhouse. Job boards and aggregators can use this feed to pull an employer's open roles without a commercial agreement.
