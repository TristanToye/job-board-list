Types of job sites, explained

Every entry in the directory is tagged by what it is, who it is for, how it makes money and how open it is to integration. Use the tags to filter, group and compare.

What it is

  • Job board (446)
    A site where employers post jobs and candidates search and apply.
  • Job aggregator (26)
    A search engine that collects listings from many sources and links candidates to them.
  • Professional network (4)
    A social or professional network where job listings are one feature.
  • Public employment service (54)
    A job service or portal run by a government or public body.
  • Applicant tracking system (22)
    Software employers use to manage hiring and publish their jobs.
  • Job distribution (23)
    Multiposting and programmatic platforms that push one job to many boards.
  • Staffing agency (27)
    An agency that supplies temporary and contract workers to employers.
  • Recruiting services (10)
    Executive search
  • Outplacement (9)
    Career transition support for laid off employees
  • Labour market information (12)
    Statistics
  • HR and recruiting technology (14)
    Software for sourcing
  • Career services (9)
    Resume
  • Freelance marketplace (10)
    A platform that matches freelancers with project based work.
  • Employer reviews (1)
    Company reviews
  • Community (1)
    A forum or community that shares job leads.
  • Directory (1)
    A list of other job sites.

How it makes money

  • Free to post (54)
    Employers can post jobs without paying.
  • Pay per post (45)
    Employers pay for each job posting.
  • Subscription (91)
    Employers pay a recurring fee or plan.
  • Pay per click (19)
    Employers pay for clicks or applications on sponsored jobs.
  • Freemium (4)
    A free tier with paid upgrades.
  • Publicly funded (3)
    Funded by government or public money.

How open it is

  • Open API (12)
    Provides an API or feed that needs no approval.
  • Self-serve API (28)
    Provides a documented API with a self-serve key.
  • API on request (13)
    Issues API keys or feeds after a request form or review.
  • Partner-only API (29)
    Programmatic access requires an approved partner or commercial agreement.
  • XML feed (24)
    Accepts or publishes jobs through XML feeds.
  • ATS integration (28)
    Receives jobs from applicant tracking systems.
  • Apply integration (4)
    Offers an apply flow that other systems can plug into.
  • Partner program (85)
    Has a partner or integration program.
  • Crawl sourced (11)
    Collects jobs by crawling employer sites.
  • Public job feed (15)
    Publishes a public job feed or API for customers' postings.
