What this directory covers

Job distribution has several layers: the employer, the applicant tracking system, programmatic and multiposting platforms, and the boards and aggregators candidates use. This directory maps all of them, with a focus on integration: which platforms publish open feeds or APIs, which require a partnership, and where the developer portals are.

  • Job boards with an open API
  • Job boards with a self-serve API key
  • Partner-only job board APIs
  • ATS systems with public job feeds

Job Board Atlas is an open dataset. Download: boards CSV, boards JSON, ATS CSV. Data is a work in progress and may be wrong: see methodology. Last built 2026-11-05.
