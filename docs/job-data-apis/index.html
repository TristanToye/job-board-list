Quick answers

Which job boards have a free public API?

Among the sites checked so far, Google for Jobs, Remotli publish job data openly without a key, and USAJOBS, Reed, Careerjet, Adzuna, Happy Monday, Jobsuche (Bundesagentur fur Arbeit), France Travail, The Muse offer an API with a self-serve key.

Where can I get job postings from many countries in one API?

Commercial job data providers collect postings from many sources; see the providers table above for the coverage each one states, U.S. Bureau of Labor Statistics, Office for National Statistics, Australian Bureau of Statistics, O*NET, Statistics Austria, Apify, Bright Data, Lightcast.

See also applicant tracking system APIs and all API access levels.
